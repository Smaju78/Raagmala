# Design references

`mockups/` holds the three redesign concepts made with Claude Fable in October 2026 (click-through prototypes
that load the real data):

- **A · Nocturne**: dark, Spotify-like, dense rows, sidebar on desktop.
- **B · প্রহর Prahar**: light/warm; the whole site follows the time of day (sky hero, prahar colours).
- **C · চিত্র Chitra**: ragamala-painting identity with a labelled swara mandala for every raag. **Chosen**,
  with B's time-of-day tint in the home hero.

To view them, serve the repository root (e.g. `python3 -m http.server` in the repo folder) and open
`/design/mockups/`. `shots/` has screenshots of each.
